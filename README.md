# BS IT Management System

A fresh class management application for the BS IT class.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase (planned; not connected yet)
- Progressive Web App support (planned)

## Local development

1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Project principles

- Separate, new project; do not reuse EduNova, Hotel Management, or Menufista code.
- Free-tier services only.
- Role-based access planned for Admin, Teacher, Student, and CR.
- Original BS IT logo will be added after the supplied asset is placed in `public/`.

## Current status

Phase 1 foundation scaffold. Authentication, database schema, dashboards, PWA manifest, and deployment are not configured yet.
